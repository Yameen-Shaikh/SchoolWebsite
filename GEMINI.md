# AYK Project

A FastAPI-based web application designed for school patterns and information.

## Tech Stack
- **Backend:** FastAPI (Python)
- **Templating:** Jinja2
- **Frontend:** Vanilla CSS, Static Files, Vanilla JS
- **Environment:** Arch Linux (WSL)
